# 私有机会客户端：B60

- 独立接口文件：`frontend/src/lib/private-import-target-api.ts`。目前没有产品页面调用；已有本地导入不会自动上传。
- 创建时生成一次 `private-import:<UUID>`，重试沿用同一 ID；更新和删除携带用户刚才看到的版本。冲突后重新阅读，不自动覆盖。
- 请求从开始到结束固定原账号，包括认证等待、读取响应和核对版本。账号切换、取消或 30 秒超时后不再接纳结果；迟到认证不能继续发请求。
- 单条读取保留完整原文；列表只取摘要。删除返回不含原文的记录，旧请求不能重新创建同一 ID。
- 回执核对账号、私有状态、版本、时间顺序、完整内容及来源标签；摘要遵守相同字段限制。导入的标签、技能建议和任意 extra_fields 均不构成官方资格依据。
- 创建、读取、列表和删除的测试使用实际 FastAPI 路由生成的合成回执。认证及数据库响应均为模拟；不证明托管环境可用。
- 16 项客户端检查通过，独立 14 个回放案例通过。两次复查发现并补齐了来源标签矛盾及摘要字段限制。
- 后续接入顺序：先完成隔离数据库验收；再增加显式云端保存/更新入口和统一私有目标读取；最后接邮件、完整简历、Tracker 与历史材料。完整模型输入接收方仍待用户确认。

接口和数据库约定见 [private_import_targets.md](private_import_targets.md)。本地存储协调与恢复见 [custom_import_updates.md](custom_import_updates.md)。
