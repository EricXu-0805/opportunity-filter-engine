# 私有机会客户端

## 账户保存与更新

- 导入页先保存到浏览器；“保存到账户”会读取当前账户副本，展示完整旧/新内容。用户确认后才上传，打开页面不会上传旧记录。
- 同一账号、同一浏览器记录派生稳定的 `private-import:<UUID>`。刷新、重试或换标签页不会另建 ID；重新创建本地记录或从另一设备独立导入仍是另一条记录，不承诺内容去重。
- 更新使用审阅时的版本。账号、本地原记录或账户版本变化后，必须重新读取和核对。已删除 ID 不自动恢复，也不另换 ID 绕过删除。
- 浏览器和账户是两份独立副本。删除账户副本不删除浏览器副本，也不删除已有申请或联系历史。
- 保存失败可能代表响应丢失；用户重新读取账户副本后再决定更新，没有自动重发写入。

## 列表、详情和 Tracker

- 收藏页独立展示账户导入、分页和失败重试；账户副本不混进原收藏数量，统一 Dashboard 总数仍待完成。
- 原文、来源和 AI 输入范围可展开查看。原文按文本渲染；技能建议和导入字段不构成已核对的资格、招聘状态或联系依据。
- `/private-imports/[id]` 显示当前账户原文及历史。删除后仅保留历史入口，不恢复旧正文。
- 私有详情可记录用户已进行的申请：必须由用户填写和确认，再沿用原申请记录接口。此操作不提交申请，不发送邮件。
- Tracker 公共和私有 ID 分开读取。私有卡片只显示身份和来源信息，明确标为未验证；不存在或已删除的目标保留历史入口。读取失败不会显示成空列表。
- 账号切换会立即隐藏旧内容；过期结果不写回新账号。私有来源不提供官方截止日期或可投递提醒的依据。

## 接口约定与验证范围

- `private-import-target-api.ts` 核对账号、ID、版本、完整内容、来源标签和时间关系。请求的认证、读取响应和版本计算有取消与 30 秒期限；ID 派生单独设 30 秒期限。
- 只读 resolver 的 `writes:false` 表示不能凭该响应调用写作或发送；个人申请记录使用独立的用户确认流程和原有权限检查。
- 前端使用真实组件和 SDK 配合模拟认证、HTTP 回执；后端使用真实路由配合模拟 GoTrue/PostgREST。原生浏览器验证亦为受控数据，不证明真实账号或托管数据库已可用。
- B60 原生 SQL 只部分验证；B61 没有重跑共享数据库或执行托管迁移。完整生产验收仍需独立完成。
